Design Principles
Minimalism
No unnecessary decorative elements. Every element serves a function. White space is a full-fledged design element.
One Font
Inter for the entire interface. JetBrains Mono only for numerical data and task codes. No decorative fonts.
Restrained Color
Neutral tones as the foundation. Color is used only for accents and statuses. No more than 2–3 colors on screen simultaneously.
Hierarchy Through Size
Element importance is determined by font size and weight, not color or decoration. The most important is the largest.
Contrast and Accessibility
Minimum 4.5:1 for text. Both modes (light/dark) are tested for readability. Color is never the sole indicator.
